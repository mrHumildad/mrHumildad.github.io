## How this site is built

pushing to `main` (GitHub Pages). No cookies, no trackers, no analytics. English
copy is inline in `index.html`; Spanish is swapped in client-side from
`assets/i18n/es.js`. Same content in both languages, so `?lang=es` adds nothing
for a crawler beyond translated strings.
